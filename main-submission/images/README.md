# Photo Naming Conventions

For examples, the following photo format should be followed:

| Image Type | 0 | 1-3   | 4     | 5   | 6 onwards        |
|------------|---|-------|-------|-----|------------------|
| Generated  | g | Index | n/r/t | '_' | The encoded word |
| Photo      | p | Index | n/r/t | '_' | The encoded word |

| 4 | Meaning       |
|---|---------------|
| n | Normal image  | 
| r | Rotated image |
| t | Tilted image  |
